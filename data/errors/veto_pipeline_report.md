# B-v4 veto를 실제로 적용했을 때 최종 EM/F1

결정 규칙: p(bridge_helped) >= threshold 이면 Full 조건 예측으로 교체, 아니면 Answer-hop only 예측(원본 shortcut-prone 기본값) 유지.

## Baseline (교체 없음)
| | EM | F1 |
|---|---|---|
| Answer-hop only (전부 유지) | 0.6158 | 0.7670 |
| Full (전부 교체했다면) | 0.5862 | 0.7597 |
